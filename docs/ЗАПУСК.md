# Dolce-Pharm LMS — запуск, демодоступы, устройство

Учебная платформа для производственной площадки: методист собирает курс из обычной инструкции и назначает его смене, оператор скачивает курс на телефон, проходит его в цеху без связи, а результат сам приходит в отчёт. После проверки формируются именной сертификат и сводный протокол.

Прототип. Все ФИО, подразделения и документы вымышлены. Бюджет — 0 ₸: только свободные компоненты, без облаков, платных API и магазинов приложений.

## Запуск на Windows

Первый раз (нужен интернет, 5–10 минут):

```powershell
.\setup.bat
```

Каждый следующий раз (интернет не нужен):

```powershell
.\start.bat
```

В окне появится рамка с адресами. Методист открывает на этом же ноутбуке `http://localhost:8000` и попадает на экран «Обучение смены». Остановка — Ctrl+C.

Требования: Windows 10/11, Python 3.10–3.12, Node.js 20+. PostgreSQL, LibreOffice и Docker ставить не нужно: база данных встроена, конвертер Office — тоже.

При первом запуске Windows спросит про доступ Python к сети — разрешите для частных и общедоступных сетей, иначе телефон не подключится.

## Телефон

Коротко: на ноутбуке включить «Мобильный хот-спот» (и выключить в нём «Энергосбережение») → подключить телефон к его сети → на ноутбуке «Настройки и телефон» → первый QR-код → установить сертификат → второй QR-код → войти → «Добавить на главный экран».

Адрес хот-спота `https://192.168.137.1:8443` постоянный: `start.bat` помечает его в рамке, иконка на телефоне продолжает работать после перезапуска. Адрес, выданный обычным Wi-Fi, меняется.

Подробно, с проверкой Service Worker и разбором сбоев: [docs/ТЕЛЕФОН.md](ТЕЛЕФОН.md).

Проверка на подключённом по USB телефоне Android (отладка по USB включена):

- `tools\phone_watch.py` — замер задержки синхронизации: когда телефон снова появился в сети и когда сервер принял записи;
- `tools\run_report.py` — что методист видит по сотруднику: попытки, время, протокол PDF;
- `tools\check_https.py` — проверка сертификата на адресе так, как её делает телефон;
- `e2e\tools\phone.mjs` — состояние приложения на телефоне: Service Worker, оболочка, локальная база, текст на экране.

```powershell
.\switch-build.bat 2
```

```powershell
.\switch-build.bat 1
```

Без номера команда показывает, какая сборка отдаётся сейчас. Исходники сборки 1 сохранены в `releases/v1-run2-verified`. Логотип взят с сайта компании (`frontend/public/brand`, `backend/app/assets/brand`) и используется только в прототипе.

## Что проверено и что нет

Матрица «критерий жюри → экран → проверка → фактический результат» с измеренными значениями: [docs/МАТРИЦА.md](МАТРИЦА.md). В ней отдельно помечено, что проверено автотестом в Chromium, что — только эмуляцией, а что нужно пройти на физическом телефоне.

Автоматические проверки запускаются одной командой и работают в отдельном контуре `test`, не трогая демонстрационные данные:

```powershell
.\run-tests.bat
```

- `backend/tests` — pytest: API, роли, синхронизация, время, редакции, документы, конвертер Office.
- `e2e/tests` — Playwright: два независимых сеанса браузера (ноутбук методиста и телефон оператора), отключение сети, повторное открытие приложения. Скриншоты каждого прогона — в `e2e/results/shots`, измерения — в `e2e/results/measurements.jsonl`.

## Что умеет

**Методист:** сводка «Обучение смены» — по каждой действующей редакции видно, сколько человек сдали, кто на проверке и кого ещё ждём, протокол открывается одной кнопкой; курс из блоков прямо в браузере (текст, PDF, видео, Word, Excel, PowerPoint, ссылка, тренажёр), порядок блоков, тест из четырёх типов вопросов, предпросмотр «глазами сотрудника», публикация, назначение сотруднику или подразделению со сроком, новая редакция с повторным ознакомлением, проверка открытых ответов, отчёты с фильтрами и автообновлением, сертификаты, сводный протокол (PDF и CSV), импорт и экспорт сотрудников, библиотека, оценка 180/360.

**Сотрудник:** ближайшее задание, путь «Скачать → Изучить → Тест → Итог» и одно главное действие на первом экране, скачивание пакета с проверкой целостности, материалы и тест без сети, черновик теста переживает закрытие приложения, автоматическая отправка, результат и сертификат, библиотека с поиском и сохранением на устройство, история аттестаций, опросы 180/360, диалоговый тренажёр.

**Руководитель:** всё, что сотрудник, плюс раздел «Участок» — результаты, время и протокол только по своему подразделению.

## Устройство

```
backend/            FastAPI, SQLAlchemy, Alembic, PostgreSQL
  app/routers/        REST API: вход, пользователи, курсы, файлы, кабинет сотрудника, отчёты, 180/360
  app/services/       приём очереди, проверка ответов, пакет курса, время, PDF, конвертер Office, HTTPS
  alembic/            миграции
  demo/               генератор учебных материалов и сами материалы
  tests/              pytest
frontend/           React, TypeScript, Vite; устанавливаемое PWA
  src/local/          IndexedDB (Dexie), очередь отправки, учёт времени, скачивание пакета
  src/sw.ts           Service Worker: оболочка без сети и фоновая отправка
  src/pages/          экраны сотрудника и методиста
e2e/                Playwright
docs/               инструкции, матрица приёмки, описание API (openapi.json)
samples/            образец CSV для импорта сотрудников
run.py              запуск и служебные команды
```

Один REST API обслуживает обе роли; описание — `http://localhost:8000/api/docs` (работает без интернета) и `docs/openapi.json`.

Как устроена работа без сети:

1. Кнопка «Скачать» получает манифест редакции (тексты, вопросы без ответов, список файлов с размерами и SHA-256) и качает файлы кусками по 1 МБ в IndexedDB. Обрыв не теряет скачанное. «Готово без сети» ставится только после проверки размера и контрольной суммы каждого файла.
2. Ответы, интервалы времени и события сначала пишутся в IndexedDB. Сдача теста и постановка в очередь — одна транзакция.
3. Очередь уходит сама: когда сервер снова доступен, при возврате в приложение, сразу после сохранения, по таймеру и через Background Sync при закрытом приложении (Chrome на Android).
4. У каждой записи есть номер, созданный на телефоне. Сервер подтверждает принятые номера; повторная отправка ничего не дублирует. Из очереди удаляется только подтверждённое.
