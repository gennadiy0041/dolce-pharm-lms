# Защита на 3 минуты

Два устройства: ноутбук (он же на проекторе) и смартфон. Три роли в команде: **ведущий** говорит, **методист** работает на ноутбуке, **оператор** готовит телефон и передаёт его Зауре Мейрамовне.

Материалы лежат в `docs/защита`:

| Файл | Для чего |
|---|---|
| `Dolce-Pharm_LMS_защита.pptx` | Презентация для проектора (PowerPoint, 16:9). Слайды 1–3 — до живого показа, 4–6 — после, 7–8 — запасные с экранами продукта. Текст выступления — в заметках к слайдам |
| `Dolce-Pharm_LMS_защита.pdf` | Та же презентация в PDF — на случай чужого компьютера или отправки организаторам |
| `Памятка для отдела обучения.pdf` | Один лист A4: его оставляют Зауре Мейрамовне. Распечатать в двух экземплярах |

## Какая сборка стоит на защите

В проекте две сборки интерфейса. Данные у них общие, переключение — одна команда.

| | Сборка 1 | Сборка 2 |
|---|---|---|
| Оформление | прежнее, зелёное | фирменное: логотип и цвета Dolce-Pharm |
| Что добавлено | — | экран методиста «Обучение смены»; путь задания «Скачать → Изучить → Тест → Итог» у оператора; вопрос на последовательность читается на телефоне без разрыва слов; сертификат и протокол с логотипом |
| Автотесты | 87 + 16 пройдено | 87 + 18 пройдено (см. `docs/МАТРИЦА.md`, раздел «Сборка 2») |
| На телефоне POCO | пройдена дважды, замеры 1,6 с и ≤ 2 с | см. `docs/МАТРИЦА.md`, раздел «Сборка 2» |
| Код скачивания, хранения и отправки | — | тот же, файлы совпадают байт в байт |

Рекомендация — **сборка 2**, при одном условии: утром на ней пройден раздел «Утренний прогон» ниже. Если прогон не сделан или что-то в нём не так — `switch-build.bat 1`, и защита идёт на сборке 1 по тому же сценарию (разница — в конце раздела «Показ»).

```powershell
.\switch-build.bat 2
```

```powershell
.\switch-build.bat 1
```

Без номера команда показывает, какая сборка отдаётся сейчас. После переключения телефон получает другую сборку сам: открыть приложение при включённой сети, смахнуть, открыть ещё раз.

## Сеть: только хот-спот ноутбука

Приложение на телефоне установлено с адреса `https://192.168.137.1:8443` — это адрес «Мобильного хот-спота» ноутбука. Он один и тот же в любом помещении. Адрес, выданный Wi-Fi зала, для показа не годится: он меняется, и иконка перестаёт открываться.

Три правила:

1. **«Энергосбережение» хот-спота выключено.** На репетиции оно было включено, и Windows погасил хот-спот, пока телефон был в авиарежиме, — ответам стало некуда уходить. Проверьте перед показом: Параметры → Сеть и Интернет → Мобильный хот-спот.
2. **После перезагрузки ноутбука хот-спот включается вручную.** Порядок: включить хот-спот → запустить `start.bat`.
3. Хот-спот включается, только пока сам ноутбук подключён к какой-нибудь сети. Интернет платформе не нужен, но Wi-Fi зала или кабель должны быть подключены.

## Утренний прогон (10 минут, один раз)

Нужен, чтобы на защите телефон показал сборку 2, которую до этого видел только тестовый браузер.

1. Включить хот-спот, запустить `start.bat` (перезапуск нужен и для того, чтобы сертификат и протокол печатались с логотипом). Выполнить `switch-build.bat 2`.
2. Телефон: подключиться к хот-споту, открыть приложение с иконки, смахнуть, открыть ещё раз. В шапке должен быть логотип Dolce-Pharm на белом фоне.
3. Иконка на главном экране остаётся прежней, пока Chrome сам не обновит её (обычно в течение суток). Чтобы новая иконка была сразу: удалить приложение с главного экрана, открыть `https://192.168.137.1:8443` в Chrome, меню ⋮ → «Добавить на главный экран» → «Установить». **Сразу после установки закрыть эту вкладку Chrome**: оставшаяся в фоне вкладка замораживается и держит хранилище приложения — 21.11 из-за неё приложение повисло на «Загружаем…», а скачивание курса оборвалось. Скачанные курсы и вход при переустановке сохраняются (хранилище у приложения и Chrome общее).
4. Под записью `operator` пройти на телефоне то же, что будет на защите: ближайшим заданием у него стоит тот же курс в редакции 3 («Повторное ознакомление»). Скачать → авиарежим → закрыть и открыть с иконки → материалы (в PDF на титуле — «редакция 3») → тест (вопрос 3 — посмотреть, что текст шага читается целиком; вопрос 4 — новый, про несовпадение редакции) → «Ответы сохранены на телефоне» → включить Wi-Fi → строка на ноутбуке в «Обучении смены». На ноутбуке: **Проверить** → **Выставить итог** → открыть сертификат и **Протокол (PDF)** — в обоих должен быть логотип.
5. Записать результат в `docs/МАТРИЦА.md`, раздел «Сборка 2». Если что-то не так — `switch-build.bat 1`.

Запись `zashita` в прогоне не трогать: за неё до показа ничего не назначают и не сдают.

## За 15 минут до защиты

1. Хот-спот включён, «Энергосбережение» выключено. `start.bat` запущен; в рамке строка `https://192.168.137.1:8443/ ← постоянный адрес (хот-спот)`.
2. `stage-account.bat` называет учётную запись для защиты без назначений и попыток (обычно `zashita` — Сейтказина Асель Маратовна; если её использовали — создаст следующую). Пароль — в `README.md`, раздел «Демодоступы».
3. **Ноутбук:** презентация `docs\защита\Dolce-Pharm_LMS_защита.pptx` открыта в режиме показа (F5) на слайде 1. В браузере — `http://localhost:8000`, вход методистом, открыт экран «Обучение смены»; F11 — браузер во весь экран. Переключение между презентацией и платформой — Alt+Tab. Масштаб страницы платформы 110–125 % (Ctrl + «+»), чтобы зал читал.
4. Карточка курса «Как проверить актуальность СОП перед началом смены» стоит первой: «редакция 3 · действует с 21.11.2026», «0 из 3 сдали», «Ждём: 3» — Ибраев (повторное ознакомление после сданной редакции 2), Абдрахманов, Ким. Если утром Ибраев сдал редакцию 3 в прогоне — будет «1 из 3» и «Ждём: 2»; ведущий называет те числа, что на экране.
5. **Телефон:** Wi-Fi хот-спота; приложение с иконки; **Профиль → Выйти**, вход под записью для защиты. На вкладке «Задания» — «Заданий пока нет», вверху — «Всё отправлено». Яркость на максимум, автоблокировка экрана — не меньше 5 минут, звук выключен.
6. Памятка распечатана. Видео в курсе без звука — так и задумано.

Обе роли на одном ноутбуке в двух вкладках одного браузера показывать нельзя: вкладки делят учётную запись. Если понадобится — окно инкогнито или другой браузер.

**Что Зауре Мейрамовна делает своими руками:** держит телефон в авиарежиме — читает инструкцию, отвечает на тест и пишет ответ на открытый вопрос; сама включает Wi-Fi. Если она стоит рядом с ноутбуком — можно предложить ей самой нажать **Выставить итог**: это её настоящая роль в продукте.

**Что остаётся у неё:** памятка; протокол и сертификат — файлами (в протоколе: **Период и таблица → Скачать PDF**).

**Редакция 3 курса.** Выпущена 21.11.2026 через обычную публикацию новой редакции. Что в ней изменено по сравнению с редакцией 2:

- четвёртый вопрос теста: «Редакция СОП на вашем рабочем месте не совпала с реестром. Что вы сделаете? Ответьте одним-двумя предложениями». Критерии для методиста: 2 балла — не начинает работу и сообщает мастеру смены; 1 балл — только одно из двух; 0 — продолжает работу или исправляет экземпляр сам;
- инструкция внутри курса — СОП-ОК-015 в редакции 3 (`backend/demo/materials/sop-ok-015-red3.pdf`): те же пять шагов, уточнён раздел «Если данные не совпали»;
- в тексте «Зачем проверять редакцию» добавлена строка про оборудование.

Вопроса про «контрольное слово» больше нет. Попытки и сертификат Ибраева с репетиции остались привязаны к редакции 2; ему назначено повторное ознакомление с редакцией 3, Ким и Абдрахманов переведены на неё. `reset-demo.bat` возвращает исходные демоданные — без редакции 3.

**Правильные ответы** (чтобы на сцене вышло «Сдал»):

- вопрос 1 — «В реестре действующих редакций на посту мастера смены»;
- вопрос 2 — только «Код документа», «Номер редакции», «Дату введения в действие»;
- вопрос 3 — не трогать. Если время есть — сверху вниз: найти на титульном листе код и номер редакции → открыть реестр → сверить код, редакцию и дату → отсканировать QR-код → расписаться в журнале;
- вопрос 4 — своими словами, например: «Не начну работу и сообщу мастеру смены». Методист ставит 2 балла.

В тесте 7 баллов (1 + 2 + 2 + 2), проходной порог — 70 %. Без вопроса 3 и с полной оценкой открытого ответа выходит 5 из 7 = 71 % — «Сдал»; так было во второй попытке на репетиции. Ошибка в вопросе 1 или 2 при пропущенном вопросе 3 — «Не сдал», как в первой. Если так вышло на сцене — не исправлять: в протоколе будет «Не аттестован», у оператора — «Осталось 2 попытки». Это тоже показывает продукт.

Почему «← К курсу», а не «Дальше» до конца: обязательных материалов в курсе два (текст и PDF). После них главная кнопка на странице курса сразу становится «Пройти тест», и листать оставшиеся шесть материалов не нужно.

**Если защита идёт на сборке 1:** экрана «Обучение смены» нет. На шаге 0:30 — **Курсы и назначения** → **Назначить** → … → **Открыть отчёт**; строка на шаге 2:00 появляется в «Отчёте по обучению»; на шаге 2:10 протокол — **Протокол аттестации** → программа → **Открыть PDF для печати**. Остальное без изменений.

### Усиленный вариант шага 1:55 — приложение закрыто

После «Ответы сохранены на телефоне» смахнуть приложение из списка недавних и только потом включить Wi-Fi. Телефон лежит с закрытым приложением, а строка на ноутбуке всё равно появляется. На репетиции это заняло 1,6 секунды; у такой строки написано «фоновая отправка (Background Sync), приложение закрыто».

Это работает в Chrome на Android. Замер сделан один раз и через две минуты без сети: после долгого простоя или при экономии заряда Android может отложить отправку. Если строка не появилась за 15 секунд — открыть приложение с иконки, ответы уйдут сразу. Когда телефон в руках у Зауре Мейрамовны, проще основной вариант.

## Если хочется показать создание курса, а не только назначение

Редакция 3 уже опубликована, поэтому шаг «методист добавляет вопрос и публикует» в показе заменён назначением. Вернуть его можно двумя способами:

- **Новая редакция на сцене.** В карточке курса на «Обучении смены» — **Новая редакция** → в черновике редакции 4 поправить любой материал (например, строку в тексте «Зачем проверять редакцию») → **Опубликовать** («Редакция 3 будет заменена») → **Назначить** Сейтказиной. Прежние попытки останутся привязаны к своим редакциям — это заодно показывает контроль редакций. Добавляет к показу около 30 секунд; инструкция внутри курса при этом останется в редакции 3.
- **Чистый контур.** `reset-demo.bat` стирает всё, включая результаты репетиции и редакцию 3, и возвращает черновик редакции 2 с прежним набором вопросов. Перед защитой так делать не нужно.

## Если останется минута — на выбор жюри

**Оценка 360.** Ноутбук: **Оценка 180/360** — видна таблица по Ибраеву, «Ответов: 0 из 4». Для этого шага на телефоне нужно войти как `operator`: вкладка **Опросы** → «Оцените себя» → **Заполнить** → поставить оценки → **Отправить**. На ноутбуке без обновления страницы появляется «Ответов: 1 из 4» и столбец «Самооценка». Пропуск («Не могу оценить») показывается прочерком, не нулём.

**Тренажёр.** Телефон: страница курса → восьмой материал «Тренажёр: в смене оказалась инструкция другой редакции» → **Начать разговор**.

- Плохая развязка: «Начинаю работу: отличия наверняка небольшие» → мастер **рассержен** → «По инструкции, которая лежала на рабочем месте. Всё как всегда» → «Серия забракована, начато расследование», с перечнем последствий.
- **«Пройти ещё раз и выбрать иначе»**. Хорошая развязка: «Не запускаю пресс и иду к мастеру смены» → мастер **встревожен** → «Лежит на месте. Я его не трогал и пресс не запускал» → мастер **доволен** → «Расписываюсь и читаю третий раздел до запуска» → «Смена началась по действующей редакции».

Тренажёр работает и в авиарежиме; исход сохраняется и после возврата связи виден методисту: **Время и входы → Тренажёр**.

## Что сказать, если спросят

- **«А если приложение закрыто?»** Ответы лежат на телефоне. В Chrome на Android браузер сам будит приложение после возврата связи: на репетиции с закрытым приложением ответы ушли за 1,6 секунды. Это один замер; после долгого простоя Android может отложить отправку — тогда ответы уйдут при открытии приложения. На iPhone фоновой отправки нет — ответы уйдут при следующем открытии.
- **«А если связь оборвётся при отправке?»** Каждая запись имеет номер, созданный на телефоне. Повторная отправка той же записи ничего не дублирует — есть автотест; на репетиции сервер получил две попытки и ни одного дубля.
- **«Откуда время изучения?»** Телефон записывает интервалы, пока экран виден и человек что-то делает; для видео — пока оно играет. При сворачивании учёт останавливается. В автотесте 60 секунд чтения и 60 секунд «свёрнуто» дали 60–61 секунду. На физическом телефоне по секундомеру это не сверялось.
- **«Где данные?»** На этом ноутбуке: PostgreSQL и папка с файлами. Никаких облаков и внешних сервисов: приложение на телефоне загружает всё только с адреса платформы.
- **«Почему участок таблетирования, у нас же маски и перчатки?»** По условию кейса ФИО, подразделения и документы вымышлены. Платформе всё равно, какой СОП: курс собирается из ваших файлов. Второй учебный курс — про переодевание в чистой зоне: шапочка, маска, комбинезон, бахилы.
- **«Логотип наш — вы его откуда взяли?»** С сайта компании, только для прототипа, который делается для вас.

## Запасной план

| Что случилось | Что делать |
|---|---|
| Приложение висит на «Загружаем…», скачивание обрывается | В Chrome на телефоне осталась вкладка с платформой. Chrome → кнопка с числом вкладок → закрыть её. Приложение оживает сразу |
| Телефон не подключается к Wi-Fi после авиарежима | Проверить хот-спот на ноутбуке: если выключился — включить. Сервер перезапускать не нужно |
| Новое задание не появилось на телефоне | Нажать вкладку «Задания» — список обновится сразу |
| После авиарежима Wi-Fi не подключился сам | Открыть настройки Wi-Fi и выбрать сеть хот-спота вручную. Приложение отправит ответы само, как только сеть появится |
| Строка не появилась за 15 секунд | Открыть приложение (если закрыто). Если открыто — нажать плашку статуса вверху → «Отправить сейчас» |
| На телефоне «Войдите заново» | Нажать «Войти», ввести пароль учётной записи. Ответы при этом не теряются |
| На телефоне прежнее зелёное оформление | Телефон ещё не получил сборку 2: при включённой сети открыть приложение, смахнуть, открыть ещё раз. Сценарий от оформления не зависит |
| Что-то не так с новым оформлением | `switch-build.bat 1` на ноутбуке; на телефоне открыть приложение дважды при включённой сети |
| Телефон недоступен совсем | Вторую роль показать в окне инкогнито на ноутбуке (`http://localhost:8000`). Отключение сети — через инструменты разработчика: F12 → Network → Offline |

## Как пересобрать материалы

Презентация собирается скриптом `tools/make_deck.py` (тексты слайдов и заметок — в нём), из корня проекта:

```powershell
.\.venv\Scripts\python.exe tools\make_deck.py
```

PDF-копию делает сам PowerPoint: Файл → Экспорт → Создать документ PDF. Готовый `.pptx` можно править и прямо в PowerPoint.

Источник памятки — `docs/защита/src/pamyatka.html`. После правки, из папки `e2e`:

```powershell
node tools\print-pdf.mjs "..\docs\защита\src\pamyatka.html" "..\docs\защита\Памятка для отдела обучения.pdf"
```

Команда печатает, поместился ли текст на лист.
