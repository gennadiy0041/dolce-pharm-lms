# Dolce-Pharm LMS: обучение смены без связи в цеху

Кейс Dolce Pharm, AI in Engineering Hackathon 2026 (трек AI for Smart Campus). Это прототип: все ФИО, участки и документы вымышлены.

**Задача.** У операторов цеха нет компьютера и связи в рабочей зоне, а изучать СОП и проходить аттестацию они обязаны. Нужна лёгкая LMS: методист сам загружает материалы (без SCORM), сотрудник учится без интернета, результат попадает в отчёт не позже чем через 30 минут после появления сети.

**Данные.** Только синтетические: вымышленные сотрудники (ФИО, должности, участки) и учебные СОП, чек-листы, реестр, презентация и видео, созданные командой (`backend/demo/make_materials.py`, источники в `backend/demo/materials/SOURCES.md`). Реальные персональные данные не используются.

**Метод.**
- Веб-кабинеты методиста, руководителя и сотрудника, у телефона — устанавливаемое PWA. Стек: React + TypeScript + Vite; FastAPI + PostgreSQL (встроенный, без установки); REST API с описанием OpenAPI для будущей связи с 1С и Битрикс24.
- Без сети: пакет курса качается кусками в IndexedDB, каждый файл сверяется по SHA-256. Ответы, время и события пишутся сначала на телефон. Очередь уходит сама: при возврате сети, по таймеру и через Background Sync при закрытом приложении. Номер записи создаётся на телефоне, поэтому повторная отправка не дублирует данные.
- Курсы из PDF, видео, Word, Excel, PowerPoint, ссылок и текста; тесты четырёх типов; библиотека с поиском; учёт входа, выхода и времени изучения; выгрузка в Excel/CSV; оценка 180/360; роли; сертификат и протокол в PDF; диалоговый тренажёр.

**Метрики: требование кейса → измерено** (телефон POCO X7 Pro, 20.11.2026; подробности в `docs/МАТРИЦА.md`)

| Показатель | До / требование | После / измерено |
|---|---|---|
| Синхронизация после появления сети | ≤ 30 мин | **1,6 с** при закрытом приложении (телефон); 1,5–2,5 с при открытом (эмуляция) |
| Работа в авиарежиме | — | 9 мин 44 с: запуск с иконки, материалы, видео, тест |
| Учёт времени | — | 60,3 с изучения → 61 с на сервере; минута в свёрнутом приложении не засчитана (автотест) |
| Дубли и потери при повторной отправке | — | 0 |
| Протокол аттестации | вручную в бумажный журнал | PDF и CSV одной кнопкой |
| Автотесты | — | pytest 87/87; Playwright: 18 пройдено, 1 пропущен |

**Ограничения.** На iPhone фоновой отправки нет: ответы уходят при открытии приложения. Проверка шла на одном телефоне Android и после 2–10 минут без сети; долгий простой и режим экономии заряда не измерялись. Время с секундомером на телефоне не сверялось. Для телефона нужен HTTPS-сертификат, его ставят один раз (`docs/ТЕЛЕФОН.md`). Демонстрационные пароли перед работой с реальными данными нужно сменить.

- Python: FastAPI, Pydantic, SQLAlchemy, Alembic, python-docx, openpyxl, python-pptx — MIT; uvicorn, pypdf, reportlab, qrcode — BSD; Pillow — MIT-CMU; cryptography — Apache-2.0/BSD; pgserver — Apache-2.0 (PostgreSQL — PostgreSQL License); psycopg — LGPL-3.0.
- JavaScript: React, React Router, Vite, vite-plugin-pwa, Workbox — MIT; Dexie, pdf.js, swagger-ui, TypeScript, Playwright — Apache-2.0; lucide — ISC.

- Логотип Dolce-Pharm взят с сайта компании и используется только в прототипе для партнёра кейса.

- Права на прототип принадлежат команде (условия кейса).

**Запуск (Windows).** Первый раз — `setup.bat` (нужен интернет), дальше — `start.bat` и `http://localhost:8000`. Демодоступы, подключение телефона и тесты описаны в `docs/ЗАПУСК.md`.

**Материалы для сдачи** лежат в `docs/сдача/`: презентация на 6 слайдов (PPTX и PDF) и видео-демо на 1 мин 49 с.
